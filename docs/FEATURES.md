# 云端减脂计划 - 功能需求规格

## 一、产品概述

云端减脂计划是一套支持多单位、多单元并行运营的减脂打卡小程序后端系统。各单元（如公司部门、学校班级）可独立配置活动规则与奖品，用户通过各类打卡任务获取积分，兑换奖品。

### 核心定位

- **多租户**：支持多单位、无限单元，数据按单元隔离
- **自治与管控**：单元管理员自主配置，全局管理员统一管控
- **多元化打卡**：步数、跑步、俯卧撑、体重、运动视频等
- **积分与兑换**：实时积分、排名、奖品兑换、发货全流程

---

## 二、角色与权限

| 角色 | 说明 | 权限范围 |
|------|------|----------|
| 全局管理员 | 平台运营方 | 单位/单元管理、全局配置、数据汇总、审批 |
| 单元管理员 | 单元负责人 | 本单元活动配置、积分规则、奖品池、成员管理、兑换审核 |
| 普通用户 | 小程序端用户 | 打卡、查看积分/排名、兑换奖品 |

---

## 三、单位与单元

### 3.1 单位 (Unit)

- 对应组织（公司、学校、机构等）
- 可创建 **无限个** 单元
- 单位登录账号：`/unit` 后台，管理名下所有单元

### 3.2 单元 (Campaign / 活动单元)

- 一个减脂计划活动的最小运营单元（如某部门、某班级）
- 每个单元独立配置：

| 配置项 | 说明 |
|--------|------|
| 活动时间 | 开始/结束日期，控制打卡与兑换是否开放 |
| 积分规则 | 各任务类型对应的积分计算规则（含阈值、上限） |
| 奖品池 | 本单元可兑换的奖品列表及兑换所需积分 |
| 兑换审核 | 是否开启兑换审核（单元级开关） |

### 3.3 数据隔离

- 排行榜、统计数据、积分、兑换记录 **全部按 unit_id + campaign_id 隔离**
- 用户加入某单元后，仅能看到该单元内的数据

---

## 四、打卡任务类型

### 4.1 任务类型（存于 campaign_custom_tasks.type）

| 类型 | 标识 | 验证方式 | 积分来源 |
|------|------|----------|----------|
| 微信步数 | `steps` | 调用微信步数 API | 按步数区间或固定积分 |
| 记录体重 | `weight` | 用户填报 | 按达标/变化量 |
| 运动视频 | `video` | 上传视频 | 审核通过后给分 |
| 自定义 | `custom` | 用户填报/可选视频 | 按 unit+points_rule 配置 |

单元在运动表中添加任务，每个任务含 type、name、unit、points_rule 等。

### 4.2 微信步数 (steps)

- 对接 `wx.getWeRunData()`，后端解密
- 支持每日上限、最低阈值、阶梯积分

### 4.3 运动视频 (video)

- 用户上传视频（OSS/本地）
- 可配置自动给分 / 需审核

### 4.4 积分规则（任务级）

- 每任务在 `points_rule` JSON 中配置

---

## 五、积分与排名

### 5.1 积分

- 实时更新：打卡成功后即时累加
- 积分历史可追溯（用于对账、申诉）
- 支持积分调整（管理员手动加减，需记录原因）

### 5.2 排行榜

- 按单元隔离
- 支持维度：总积分、周积分、任务完成数等
- 可配置展示周期（日榜/周榜/总榜）

---

## 六、奖品兑换

### 6.1 奖品池（单元自定义）

- 每个单元维护自己的奖品列表
- 字段：名称、封面、轮播图、所需积分、详情（富文本编辑器）

### 6.3 兑换流程

1. 用户选择奖品，发起兑换
2. **签名确认**：用户电子签名（图片或画板）
3. **可选审核**：若单元开启审核，需单元管理员审批
4. 通过后扣减积分
5. **发货**：管理员填写快递单号，用户可查询物流

### 6.4 兑换记录

- 状态：待审核、已通过、已拒绝、已发货、已完成
- 记录：兑换时间、用户、奖品、积分、签名、审核人、物流单号

---

## 七、接口分层

### 7.1 小程序端 `/api`

- 登录、用户信息
- 单元列表、加入单元
- 打卡（步数、俯卧撑、跑步、体重、等等任务）
- 积分、排行榜
- 奖品列表、发起兑换、签名确认、兑换记录

### 7.2 单元管理端 `/unit`

- 活动配置（时间、积分规则）
- 奖品池管理
- 成员管理
- 兑换审核、发货（填写单号）
- 视频审核（若启用）
- 本单元统计数据

### 7.3 全局管理端 `/admin`

- 单位、单元 CRUD
- 全局配置、全局统计
- 跨单元数据汇总

---

## 八、技术要点

### 8.1 微信相关

- `wx.login` → code 换取 openid/unionid
- `wx.getWeRunData()` → 加密数据，后端用 session_key 解密步数

### 8.2 文件存储

- 运动视频、签名图片：本地 `public/uploads/` 或 阿里云 OSS

### 8.3 数据隔离

- 所有查询带 `unit_id`、`campaign_id` 过滤
- 中间件校验：单元管理员只能访问其管理单元
