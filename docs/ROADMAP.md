# 云端减脂计划 - 开发路线图与任务拆解

## 阶段总览

| 阶段 | 名称 | 预计工期 | 产出 |
|------|------|----------|------|
| Phase 1 | 基础架构与单元模型 | 3-5 天 | 单元 CRUD、成员、数据隔离 |
| Phase 2 | 打卡任务与积分 | 5-7 天 | 多种打卡、积分规则、排行榜 |
| Phase 3 | 奖品与兑换 | 4-5 天 | 奖品池、兑换流程、审核、发货 |
| Phase 4 | 微信步数与视频 | 3-4 天 | 步数解密、视频上传与审核 |
| Phase 5 | 管理端完善 | 2-3 天 | 统计报表、全局管控 |

---

## Phase 1：基础架构与单元模型

### 1.1 数据库

- [ ] **任务 1.1.1** 新建 `campaigns` 表（单元）
- [ ] **任务 1.1.2** 新建 `campaign_members` 表（单元成员）
- [ ] **任务 1.1.3** 调整 `users` 与单元关系（支持多单元，通过 campaign_members 关联）
- [ ] **任务 1.1.4** 编写迁移脚本，插入测试数据

### 1.2 模型与服务

- [ ] **任务 1.2.1** 创建 `Campaign` 模型
- [ ] **任务 1.2.2** 创建 `CampaignMember` 模型
- [ ] **任务 1.2.3** 创建 `CampaignService`（单元 CRUD、加入/退出、成员列表）

### 1.3 单元管理端 `/unit`

- [ ] **任务 1.3.1** 单元列表页（本单位下的所有单元）
- [ ] **任务 1.3.2** 单元创建/编辑（名称、活动时间、状态）
- [ ] **任务 1.3.3** 单元成员管理（邀请码/扫码加入、成员列表、移除）
- [ ] **任务 1.3.4** Unit 中间件：登录后自动注入 unit_id，校验权限

### 1.4 全局管理端 `/admin`

- [ ] **任务 1.4.1** 单位管理（已有）— 确认支持多单元入口
- [ ] **任务 1.4.2** 单元管理页（按单位筛选、创建单元、编辑、启用/禁用）
- [ ] **任务 1.4.3** 单元列表支持「单位 → 单元」层级展示

### 1.5 小程序 API `/api`

- [ ] **任务 1.5.1** 用户可加入的单元列表 `GET /api/campaigns`
- [ ] **任务 1.5.2** 加入单元 `POST /api/campaigns/:id/join`（需邀请码或公开加入）
- [ ] **任务 1.5.3** 我的单元 `GET /api/user/campaigns`
- [ ] **任务 1.5.4** 单元详情（活动时间、规则说明）

### 交付物

- 单元与成员数据模型可用
- 单元管理员可创建/编辑单元、管理成员
- 全局管理员可查看/管理所有单元
- 小程序用户可加入单元并查看我的单元

## Phase 2：打卡任务与积分

### 2.1 数据库

- [ ] **任务 2.1.1** 新建 `check_ins` 表（打卡记录）
- [ ] **任务 2.1.2** 新建 `points_logs` 表（积分流水）
- [ ] **任务 2.1.3** `campaigns` 表增加 `points_rules` JSON 字段

### 2.2 模型与服务

- [ ] **任务 2.2.1** 创建 `CheckIn` 模型
- [ ] **任务 2.2.2** 创建 `PointsLog` 模型
- [ ] **任务 2.2.3** 创建 `PointsService`（计算积分、写入流水、汇总用户积分）
- [ ] **任务 2.2.4** 创建 `CheckInService`（打卡校验、防重复、积分计算调用）

### 2.3 打卡任务实现

- [ ] **任务 2.3.1** 俯卧撑打卡 `POST /api/checkins`（type=pushups, value=次数）
- [ ] **任务 2.3.2** 跑步打卡 `POST /api/checkins`（type=running, value=距离/时长）
- [ ] **任务 2.3.3** 体重打卡 `POST /api/checkins`（type=weight, value=体重）
- [ ] **任务 2.3.4** 步数打卡（Phase 4 实现，此处预留接口）
- [ ] **任务 2.3.5** 视频打卡（Phase 4 实现，此处预留接口）

### 2.4 积分规则引擎

- [ ] **任务 2.4.1** 解析 `points_rules`，实现各类型积分计算
- [ ] **任务 2.4.2** 每日上限、最低阈值校验
- [ ] **任务 2.4.3** 同一天同类型防重复（步数/体重等可每日一次）

### 2.5 单元管理端 - 积分规则配置

- [ ] **任务 2.5.1** 单元编辑页增加「积分规则」配置区块
- [ ] **任务 2.5.2** 各任务类型规则表单（阈值、每单位积分、每日上限）

### 2.6 排行榜

- [ ] **任务 2.6.1** `GET /api/campaigns/:id/ranking`（总积分/周积分，按单元隔离）
- [ ] **任务 2.6.2** `GET /api/user/points` 用户积分查询
- [ ] **任务 2.6.3** 排行榜缓存或索引优化（按需）

### 2.7 打卡记录查询

- [ ] **任务 2.7.1** `GET /api/checkins` 用户打卡历史（分页、按类型筛选）
- [ ] **任务 2.7.2** 单元端：本单元打卡记录列表（用于统计与审核）

### 交付物

- 俯卧撑、跑步、体重打卡可用
- 积分实时更新，流水可追溯
- 排行榜按单元隔离
- 单元管理员可配置积分规则

## Phase 3：奖品与兑换

### 3.1 数据库

- [ ] **任务 3.1.1** 新建 `prizes` 表
- [ ] **任务 3.1.2** 新建 `exchanges` 表
- [ ] **任务 3.1.3** `campaigns` 表增加 `exchange_review`、`points_multiplier`

### 3.2 模型与服务

- [ ] **任务 3.2.1** 创建 `Prize` 模型
- [ ] **任务 3.2.2** 创建 `Exchange` 模型
- [ ] **任务 3.2.3** 创建 `ExchangeService`（兑换校验、扣积分、扣库存、状态流转）

### 3.3 奖品池

- [ ] **任务 3.3.1** 单元端：奖品列表 CRUD
- [ ] **任务 3.3.2** 单元端：奖品上/下架、库存、每人限兑
- [ ] **任务 3.3.3** 小程序：`GET /api/campaigns/:id/prizes` 可兑换奖品列表
- [ ] **任务 3.3.4** 积分阈值上浮：兑换时 `points_required × multiplier`

### 3.4 兑换流程

- [ ] **任务 3.4.1** 发起兑换 `POST /api/exchanges`（奖品、收货地址）
- [ ] **任务 3.4.2** 签名确认：`POST /api/exchanges/:id/sign`（上传签名图片）
- [ ] **任务 3.4.3** 单元端：兑换审核列表（待审核、已通过、已拒绝）
- [ ] **任务 3.4.4** 单元端：审核通过/拒绝接口
- [ ] **任务 3.4.5** 单元端：发货（填写快递单号）`PUT /unit/exchanges/:id/ship`
- [ ] **任务 3.4.6** 小程序：我的兑换记录 `GET /api/user/exchanges`
- [ ] **任务 3.4.7** 若单元关闭审核：签名后直接通过，扣积分

### 3.5 兑换校验

- [ ] **任务 3.5.1** 积分是否足够（考虑 multiplier）
- [ ] **任务 3.5.2** 库存是否充足
- [ ] **任务 3.5.3** 每人限兑次数
- [ ] **任务 3.5.4** 活动是否在有效期内

### 交付物

- 单元可配置奖品池、积分上浮
- 用户可发起兑换、签名确认
- 单元管理员可审核、发货
- 兑换全流程闭环

## Phase 4：微信步数与视频

### 4.1 微信步数

- [ ] **任务 4.1.1** 保存 `session_key`（wxlogin 时从微信接口获取并缓存/入库）
- [ ] **任务 4.1.2** 步数解密接口：接收 `encryptedData`、`iv`，解密得到步数
- [ ] **任务 4.1.3** `POST /api/checkins` type=steps，传入加密数据，后端解密后写入
- [ ] **任务 4.1.4** 步数积分规则：按区间/阶梯计算，每日上限
- [ ] **任务 4.1.5** 同一用户同日步数只计一次

### 4.2 俯卧撑（上传视频）

- [ ] **任务 4.2.1** 小程序端上传俯卧撑打卡视频（`POST /api/checkins`，type=pushups，支持视频文件）
- [ ] **任务 4.2.2** 本地或 OSS 存储视频，生成预览图
- [ ] **任务 4.2.3** 支持自动积分或管理员审核（按单元配置，审核通过后发放积分）
- [ ] **任务 4.2.4** 单元端俯卧撑视频列表，展示/审核（通过、拒绝、备注）
- [ ] **任务 4.2.5** 俯卧撑积分规则：按次数分档、每日上限、视频必传/可选配置
- [ ] **任务 4.2.6** 俯卧撑任务校验：同日仅计一次、校验视频有效性


### 4.3 配置

- [ ] **任务 4.3.1** 积分规则中增加 steps、video 配置项
- [ ] **任务 4.3.2** 单元端规则表单补充步数、视频规则

### 交付物

- 步数打卡对接微信，自动解密
- 视频打卡支持上传与审核
- 积分规则覆盖全部任务类型

## 附录：接口清单汇总

### 小程序 API `/api`（需 JWT）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /campaigns | 可加入的单元列表 |
| GET | /campaigns/:id | 单元详情 |
| POST | /campaigns/:id/join | 加入单元 |
| GET | /user/campaigns | 我的单元 |
| POST | /checkins | 打卡（steps/pushups/running/weight/video） |
| GET | /checkins | 打卡记录 |
| GET | /campaigns/:id/ranking | 排行榜 |
| GET | /user/points | 我的积分 |
| GET | /campaigns/:id/prizes | 奖品列表 |
| POST | /exchanges | 发起兑换 |
| POST | /exchanges/:id/sign | 签名确认 |
| GET | /user/exchanges | 我的兑换记录 |
| POST | /upload/video | 视频上传 |

### 单元管理端 `/unit/api`

| 方法 | 路径 | 说明 |
|------|------|------|
| GET/POST | /campaigns | 单元 CRUD |
| GET | /campaigns/:id/members | 成员列表 |
| POST | /campaigns/:id/members/remove | 移除成员 |
| PUT | /campaigns/:id | 编辑单元（含积分规则） |
| GET/POST/PUT | /prizes | 奖品 CRUD |
| GET | /exchanges | 兑换列表 |
| PUT | /exchanges/:id/approve | 审核通过 |
| PUT | /exchanges/:id/reject | 审核拒绝 |
| PUT | /exchanges/:id/ship | 发货 |
| GET | /checkins | 打卡记录（含视频待审核） |
| PUT | /checkins/:id/review | 视频审核 |

### 全局管理端 `/admin/api`

| 方法 | 路径 | 说明 |
|------|------|------|
| GET/POST | /units | 单位 CRUD |
| GET/POST | /campaigns | 单元 CRUD（按单位） |
| GET | /stats | 全局统计 |
